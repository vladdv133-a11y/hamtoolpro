# HamTool Pro

- Added expandable source catalog via `Sources/sources.csv`.
- Supports up to 5,000 imported source rows, with hostname validation and deduplication.
- Every source gets a base module before recipe variants are added.
- CSV is copied to build output automatically.
- Clarified that imported entries are search destinations, not live API integrations.
- Preserves the 2.3.2 scrollable UI and optional Rust helper.

This archive contains a starter CSV, not 5,000 preloaded distinct websites. Add verified public sources to the CSV to expand it.
